# UPL checklist

Implementation gate for M7 from DESIGN.md §5. Unauthorized practice of law is a build constraint, not a disclaimer.

1. Describes only. Output says what a section states. It does not tell the buyer what to do.
2. Templated output. Every section comes from a versioned template. No freeform drafting at runtime.
3. No drafting. Output does not write new clause language or suggest substitute text.
4. No enforceability opinions. Output does not say whether a clause is valid, binding, or legal in a state.
5. Ask my agent on every section. Each section carries a control that routes that section to the licensee thread.
